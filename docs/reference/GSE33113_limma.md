# limma result of a gene expression data

The differential expressed analysis result between CMS4 colon cancer
subtype and non-CMS4 of a gene expression dataset with GEO
number-"GSE33113" using R package *limma*.

## Usage

``` r
GSE33113_limma
```

## Format

An object of class `data.frame` with 21656 rows and 6 columns.

## Examples

``` r
data(GSE33113_limma)
```
