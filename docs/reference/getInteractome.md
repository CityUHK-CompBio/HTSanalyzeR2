# Accessors for the 'interactome' slot of a 'NWA' object.

This function get the interactome used in 'NWA' analysis.

## Usage

``` r
# S4 method for class 'NWA'
getInteractome(object)
```

## Arguments

- object:

  An object of 'NWA'.

## Value

This function will return interactome used in 'NWA' analysis.

## Examples

``` r
data(d7_nwa)
s1 <- getInteractome(d7_nwa)
```
